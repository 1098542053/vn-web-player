# VN-Web Player

Visual Novel Web Reader - 视觉小说网页阅读器

基于 Express、PixiJS 和 Live2D 的网页视觉小说阅读器。

## Features / 功能

- Story scenario parsing and display / 剧本解析与显示
- BGM and voice playback / BGM 和语音播放
- Live2D character animation (Cubism 2.1/4) / Live2D 角色动画
- Background image rendering / 背景图渲染
- Docker deployment support / Docker 部署支持

## Note / 注意

Resource files (data/ directory) are not included in this repository.
资源文件（data/ 目录）未包含在此仓库中。
